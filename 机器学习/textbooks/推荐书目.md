# 机器学习推荐书目

以下按本课程系统学习的推荐优先级由高到低排列，优先考虑适合作为主线的教材，再列补充与进阶读物。

1. **李航：《统计学习方法》**，第 2 版（中文教材）。适合围绕监督学习与无监督学习的典型方法整理数学模型、推导和算法步骤，尤其适合本项目感知机、支持向量机、EM、隐马尔可夫模型等分章主题的研读。[出版社介绍](https://www.tup.com.cn/booksCenter/book_08132901.html)。

2. **Gareth James、Daniela Witten、Trevor Hastie、Robert Tibshirani、Jonathan Taylor：*An Introduction to Statistical Learning: with Applications in Python***（英文教材）。适合结合代码理解回归、分类、重采样、正则化与模型评价，建议用配套实验补充数学推导。作者网站提供教材与课程资料。[作者教材主页](https://www.statlearning.com/)。

## 学习建议

- **先修知识。** 建议掌握线性代数、多元微积分、概率统计与基本优化，并能使用 Python 处理数据和实现简单算法。学习时应同时理解模型假设、训练目标、求解算法和泛化评价。

- **阅读顺序。** 先学习线性回归、分类与训练集和测试集的划分，再研究模型复杂度、交叉验证和正则化，随后学习核方法、集成方法和潜变量模型。建议每学一种方法都完成一个小实验，并将训练目标值、预测误差和泛化表现分别记录。数值结果应与数据划分和评价指标一起解释。
