# 学习笔记

本项目按学科整理数学、概率统计、优化与机器学习等学习笔记，使用 LaTeX 撰写，并通过根目录的 `researchnotes.sty` 统一排版。

每份笔记使用一个独立的中文文件夹，文件夹名称省略“笔记”，主文件名与文档标题保持一致，例如 `强化学习/强化学习笔记.tex`。参考书放在对应学科的 `books/` 中，笔记专用的图片、章节源文件等资源也放在该学科文件夹内。

各学科的 `books/` 按需建立。当前 `强化学习/build/` 中包含 PDF 和编译中间文件；后续编译与交付应遵循以下统一约定：

- `tmp/<学科文件夹名称>/`：存放 `.aux`、`.log`、`.toc` 等中间文件及待检查的 PDF。
- 根目录 `build/`：仅存放检查通过的最终 PDF，例如 `build/强化学习笔记.pdf`；该目录由编译命令按需创建。
- 校验报告、预览图片和临时脚本等也放入根目录 `tmp/`，可按任务建立子目录。

## 编译笔记

使用 XeLaTeX 编译。以下命令在项目根目录执行，以数学分析笔记为例：

```sh
mkdir -p tmp/数学分析 build
xelatex -interaction=nonstopmode -halt-on-error -file-line-error \
  -output-directory=tmp/数学分析 数学分析/数学分析笔记.tex
xelatex -interaction=nonstopmode -halt-on-error -file-line-error \
  -output-directory=tmp/数学分析 数学分析/数学分析笔记.tex
```

连续编译两次，并确认目录和交叉引用已经稳定。检查 `tmp/数学分析/数学分析笔记.log`，排除编译错误、未定义引用、缺字及明显的公式或文字越界；同时查看生成的 PDF，检查本次修改涉及的页面及分页效果。确认通过后，仅将最终 PDF 复制到根目录 `build/`：

```sh
cp tmp/数学分析/数学分析笔记.pdf build/数学分析笔记.pdf
```

也可以在学科文件夹中执行编译，例如在 `数学分析/` 中先运行 `mkdir -p ../tmp/数学分析`，再将上述 XeLaTeX 命令的源文件参数改为 `数学分析笔记.tex`，输出目录参数改为 `-output-directory=../tmp/数学分析`。各笔记通过 `\input@path` 将父目录加入搜索路径，以加载共享样式。

编译其他笔记时，相应替换学科文件夹名称和主文件名。`tmp/` 用于可重新生成的临时产物，清空后可在下一次编译时重新创建所需子目录。

完整的撰写、审阅和交付要求见 [AGENTS.md](AGENTS.md)。仅修改 README 等不影响排版的说明文件时，无须重新编译笔记。
