## 阅读与编译

仓库仅保存源文件与配置，PDF 和编译中间文件不纳入版本控制。安装含中文支持的 TeX 环境后，使用 XeLaTeX 编译；共享样式见 [researchnotes.sty](researchnotes.sty)。以强化学习笔记为例，在项目根目录执行：

```sh
mkdir -p tmp/强化学习
xelatex -interaction=nonstopmode -halt-on-error -output-directory=tmp/强化学习 强化学习/强化学习笔记.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=tmp/强化学习 强化学习/强化学习笔记.tex
```

两次编译用于更新目录和交叉引用，PDF 输出至 `tmp/强化学习/`。其他笔记请相应替换路径，早期文件的依赖以各自导言区为准。

## 参与贡献

每位参与者都可以为项目贡献自己的理解。欢迎通过 [Issue](https://github.com/weijieliu-cs/Mathematics/issues) 提出问题，或提交 [PR](https://github.com/weijieliu-cs/Mathematics/pulls) 纠错、补充证明、例题与解法。改一个符号、补一个例子都很有帮助。

请注明文件及具体位置，每个 PR 尽量围绕一个主题；新增章节或较大调整请先讨论。修改遵循 [协作规范](AGENTS.md)，沿用共享样式、注明参考来源，提交前检查内容与源文件语法。PR 由维护者审核后合并。
