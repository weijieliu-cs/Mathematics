# 数学与机器学习笔记

本项目是一套面向初学者和自学者、持续整理中的中文数学与机器学习笔记，采用 LaTeX 撰写，涵盖概念、定理证明、方法推导与习题解答。各门课程的内容完整程度不同，阅读前可先查看下方的整理进度。

我们希望把概念讲清楚，把推理写明白，交代必要的预备知识与关键步骤，让不同起点的学习者都能循序渐进地走向理解。数学的深刻不必以晦涩来彰显，每一份求知的热忱都值得尊重。欢迎一起讨论、勘误与补充，让笔记在协作中持续完善。

## 目录与阅读方式

各课程按以下结构组织；部分分类可能暂时为空，具体内容以对应目录为准。

```text
课程名称/
├── textbooks/            推荐书目与教材信息
├── 笔记与习题/
│   ├── 教材研读/          按教材或章节组织的学习笔记
│   ├── 专题整理/          围绕具体概念、定理或方法的独立专题
│   └── 习题与竞赛/        习题、解答与竞赛题目
└── archive/              历史材料（仅部分课程设有）
```

系统学习时，可先查看课程 `textbooks/` 中的推荐书目，再结合 `教材研读/` 阅读与推导；查阅具体问题可进入 `专题整理/`，练习与复习可进入 `习题与竞赛/`。各类材料仍在逐步补充，章节框架或已有文件不等同于完整课程。

## 编译 LaTeX 源文件

安装包含中文支持、XeLaTeX 和 latexmk 的 TeX 发行版（如 [TeX Live](https://tug.org/texlive/)），并以仓库根目录在 VS Code 中打开项目，安装 [.vscode/extensions.json](.vscode/extensions.json) 推荐的 [LaTeX Workshop](https://github.com/James-Yu/LaTeX-Workshop/wiki/Compile)。请保留根目录的 [researchnotes.sty](researchnotes.sty) 和笔记所需的图片等资源。

仓库已在 [.vscode/settings.json](.vscode/settings.json) 中内置 **XeLaTeXmk (For Chinese)** 配方，并将其设为默认配方。打开需要编译的主 `.tex` 文件，通过命令面板执行 `LaTeX Workshop: Build LaTeX project` 即可编译。该配方调用 `latexmk -xelatex`，由 [latexmk](https://ctan.org/pkg/latexmk) 自动完成目录、交叉引用等所需的多轮编译。

在此配置下，PDF 和 SyncTeX 文件输出到主 `.tex` 文件所在目录，辅助文件集中保存在仓库根目录的 `tmp/build/`。需要清理时，可执行 `LaTeX Workshop: Clean up auxiliary files`；清理命令使用 `latexmk -c`，并传入与编译一致的辅助目录和输出目录。仓库不指定自动编译和自动清理的触发时机，沿用成员的用户设置或插件默认行为；保存时自动编译等使用习惯可在个人设置中调整。

不使用 VS Code 时，可在仓库根目录的 Bash 或 Zsh 终端执行以下命令，以《贝叶斯公式》为例：

```bash
note_dir="概率论与数理统计/笔记与习题/专题整理/贝叶斯公式"
latexmk -synctex=1 -interaction=nonstopmode -file-line-error -xelatex \
  -auxdir=tmp/build -outdir="$note_dir" "$note_dir/贝叶斯公式.tex"
```

编译其他笔记时，替换 `note_dir` 和命令末尾的 `.tex` 文件名。编译参数及输出位置与上述 VS Code 配置一致：PDF 和 SyncTeX 文件位于笔记目录，辅助文件位于仓库根目录的 `tmp/build/`。
