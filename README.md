# 数学与机器学习笔记

这是我在学习数学与机器学习过程中持续整理的中文笔记，记录对基本概念、定理证明、推导方法和典型问题的理解。希望通过公开这些学习积累，与有共同兴趣的读者交流，也欢迎大家一起纠错、补充和完善。

项目由 [weijieliu-cs](https://github.com/weijieliu-cs) 发起并维护。内容按学科组织，采用 LaTeX 撰写，适合结合教材学习、复习和查阅。各部分仍在持续整理，覆盖范围与完成程度不一，论述和解答也可能存在疏漏，欢迎指出具体问题。

## 阅读与编译

仓库保存笔记源文件与配置，PDF 和编译中间文件不纳入版本控制。可以直接查看 `.tex` 源码，也可以克隆仓库后在本地编译阅读。

笔记使用 XeLaTeX 编译，共享样式位于根目录的 [researchnotes.sty](researchnotes.sty)。请准备包含中文支持及所需宏包的 TeX 环境，例如完整安装的 TeX Live 或 MacTeX，并保留仓库目录结构。

以强化学习笔记为例，在项目根目录执行：

```sh
mkdir -p tmp/强化学习
xelatex -interaction=nonstopmode -halt-on-error -output-directory=tmp/强化学习 强化学习/强化学习笔记.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=tmp/强化学习 强化学习/强化学习笔记.tex
```

两次编译用于更新目录和交叉引用，生成的 PDF 位于 `tmp/强化学习/`。若修改其他笔记，请相应替换源文件与输出目录；早期文件的依赖以各自导言区为准。

## 参与贡献

欢迎通过 [Issues](https://github.com/weijieliu-cs/Mathematics/issues) 讨论问题，或通过 [Pull Requests](https://github.com/weijieliu-cs/Mathematics/pulls) 提交修改。无需一次完成整个章节，针对一个具体问题的小幅改进同样有价值。

欢迎的贡献包括：

- 修正错别字、公式错误、符号不一致和失效引用。
- 补充定理的适用条件、证明中的关键步骤，或澄清容易混淆的概念。
- 增加有助于理解的例题、反例、习题解法和可核验的参考来源。
- 完善已有章节；新增大段内容或调整章节结构前，请先通过 Issue 讨论范围与提纲。

报告问题时，请提供文件路径、章节或公式位置，说明疑问或错误；如果已有修正思路或依据，也请一并附上。

提交修改时，请先阅读 [项目协作与教材质量规范](AGENTS.md)，Fork 仓库后在自己的分支修改，再提交 PR。每个 PR 尽量围绕一个主题，说明修改内容、理由以及实际完成的检查。通常只需修改 `.tex` 源文件，并核对数学内容、符号、LaTeX 语法及交叉引用；如涉及编译问题，请附相关环境与错误日志，无需提交生成的 PDF 或中间文件。

请沿用已有章节结构和共享样式，引用外部内容时注明来源，不提交未经授权转载的教材、扫描件或图表。PR 由维护者审核后合并，以保持论述、符号和内容质量的一致性。
