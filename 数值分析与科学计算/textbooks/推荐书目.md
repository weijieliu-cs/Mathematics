# 数值分析与科学计算推荐书目

**先修知识。** 建议掌握微积分、线性代数和常微分方程基础，并能使用 Python、Julia 或 MATLAB 中的一种完成基本计算。学习过程中需要同时关注数学误差、浮点运算和程序实现。

**主线教材。** Timothy Sauer，*Numerical Analysis*，第 3 版。适合作为本科数值分析的系统入口，学习非线性方程、线性方程组、插值、数值积分与微分方程数值方法等内容。建议结合小型程序验证误差随步长、迭代次数和问题规模的变化。[出版社介绍](https://www.pearson.com/en-us/subject-catalog/p/Sauer-Numerical-Analysis-Subscription-3rd-Edition/P200000006340/9780137982189)。

**线性代数深化。** Lloyd N. Trefethen、David Bau，*Numerical Linear Algebra*。适合进一步理解矩阵分解、最小二乘、条件数、稳定性和特征值计算，是数值分析与机器学习之间的重要衔接读物。建议在熟悉基本线性代数后，重点比较算法的数学表达与浮点计算行为。[出版社介绍](https://epubs.siam.org/doi/book/10.1137/1.9781611977165)。

**阅读顺序。** 先理解舍入误差、截断误差与条件数，再学习线性系统、非线性方程和逼近，随后进入积分与微分方程数值解。每种算法建议记录输入、迭代规则、停止条件和误差依据；实验中同时检查残差与真实误差，分析问题病态性和算法不稳定性的区别。
